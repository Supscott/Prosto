# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 0.1.x   | :white_check_mark: |
| < 0.1   | :x:                |

## Reporting a Vulnerability

We take the security and privacy of Prosto Browser very seriously.

If you believe you have discovered a security vulnerability in Prosto Browser:
1. **Do NOT open a public GitHub issue.**
2. Please report the issue through [GitHub Private Vulnerability Reporting](https://github.com/Supscott/browser/security/advisories/new) on the repository.
3. Include detailed reproduction steps, proof of concept code/URLs if applicable, and the impacted Android version.

We will acknowledge receipt within 48 hours and work with you to analyze and remediate the issue before any public disclosure.
